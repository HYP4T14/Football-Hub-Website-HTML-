Project Description

This project provides a comprehensive overview of the Indonesian League One, covering everything from its history and the clubs that shaped Indonesia's football culture to the list of teams competing in the current (2026/27) season. It enables both myself and others to learn about the history of Indonesian football.

Project Objectives

This project serves as a learning exercise for the early stages of my web development journey, specifically focusing on HTML. After studying the material, I realized the importance of putting it into practice; therefore, I created this HTML-based website—"Football Hub"—as a practical case study.
